# Frontend LinkLab

Interface React/JSX e Vite. Veja a documentação completa no [README da raiz](../README.md).

```powershell
npm ci
npm run dev
```

O backend deve estar na porta 8000. Copie `.env.example` para `.env` para personalizar o proxy.

Verificações: `npm test`, `npm run lint` e `npm run build`.
Os testes usam o executor nativo do Node e verificam o cliente da API; não simulam interações no navegador.
